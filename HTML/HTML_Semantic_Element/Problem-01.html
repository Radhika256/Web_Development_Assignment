Academic Programs

Bachelor of Technology

The B.Tech program provides strong foundations in engineering, programming, problem-solving and emerging technologies. Students receive opportunities for projects, internships and practical training.

The BCA program focuses on computer applications, software development, databases, web technologies and information systems.

Application Process

  1. Read the program eligibility requirements.
  2. Select your preferred academic program.
  3. Complete the online application form.
  4. Upload the required academic information.
  5. Pay the applicable application fee.
  6. Submit the application and save the confirmation.
  7. Attend the selection or counselling process if required.
