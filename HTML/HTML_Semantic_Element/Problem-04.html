Product Overview

Engineered for professional creators, software engineers, and power users, the Dell XPS 16 (9640) pairs breakthrough processing capability with a stunning InfinityEdge display. Experience seamless heavy multitasking powered by integrated Intel AI Boost NPUs, keeping thermal boundaries constrained while maintaining peak processing outputs down to optimal H2O vapor chamber liquid cooling performance.

Base XPS 16 configurations start at $1,899.00 with memory capacities expanding up to 64GB LPDDR5x running at 7467 MT/s. Every unit undergoes factory display calibration to deliver 100% DCI-P3 color precision.

Hardware Terminology Glossary

RAM
Random Access Memory; high-speed LPDDR5x unified memory soldered directly for ultra-low latency workstation tasks.
SSD
Solid State Drive; PCIe Gen 4 NVMe storage providing read speeds up to 7000 MB/s for instantaneous file access.
Refresh Rate
The dynamic rate (varying between 20Hz and 120Hz) at which the OLED panel redraws image frames per second.
Warranty
Dell Premium Support coverage providing on-site repair, hardware inspection, and accidental damage service.
