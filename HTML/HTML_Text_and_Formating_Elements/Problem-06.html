My Programming Notes

Programming languages are used to give instructions to computers and create different types of software and applications. Each programming language has its own syntax, features, and common uses. Below are some beginner-friendly notes and examples for JavaScript, Java, and Python.

JavaScript

JavaScript is a popular programming language mainly used to make web pages interactive and dynamic. It can be used to respond to button clicks, change webpage content, create animations, validate forms, and build complete web applications. JavaScript can also be used outside the browser for server-side programming and other applications.

An important concept in JavaScript is the use of variables to store information. The let keyword can be used to declare a variable whose value can be changed later. 

let message = "Hello World";

console.log(message);

if (message) {
    console.log("The message is ready.");
}

In this example, the variable message stores the text "Hello World". The console.log() statement displays the message. The indentation inside the if statement is also preserved because the code is written inside the pre and code elements.

Java

Java is a widely used programming language that is commonly used for building desktop applications, web applications, enterprise software, and many other types of programs. Java is known for its portability, which means that Java programs can run on different systems using the Java Virtual Machine. It is also commonly taught to beginners because it introduces important programming concepts such as variables, classes, objects, methods, and conditions.

An important concept in Java is the class. A Java program can contain a class that holds the methods and instructions needed by the program. The main method is the starting point for a simple Java application. 

public class HelloWorld {
    public static void main(String[] args) {
        String message = "Hello World";

        System.out.println(message);

        if (message != null) {
            System.out.println("Java is running.");
        }
    }
}

In this example, a class named HelloWorld contains the main method. A String variable stores the text "Hello World". The System.out.println() statement prints the message. Notice that the spaces and line breaks used for indentation are preserved inside the pre and code elements.

Python

Python is a high-level programming language known for having simple and readable syntax. It is used for many purposes, including web development, automation, data analysis, artificial intelligence, machine learning, scientific programming, and general software development. Python is especially popular among beginners because its syntax is relatively easy to understand.

An important concept in Python is indentation. Python uses indentation to show which statements belong to a block of code. Proper indentation is therefore an important part of writing correct Python programs. 

message = "Hello World"

print(message)

if message:
    print("Python is running.")
    print("Indentation is important.")

In this example, the variable message contains the text "Hello World". The print() function displays the value of the variable. The two statements inside the if condition are indented to show that they belong to that block. The indentation and line breaks remain visible because the example is placed inside pre and code elements.

Summary

JavaScript, Java, and Python are useful programming languages with different features and common applications. JavaScript is especially important for interactive web pages, Java is widely used for applications and enterprise software, and Python is popular for automation, data-related work, artificial intelligence, and general programming. Learning simple examples such as displaying "Hello World" is a good way for beginners to understand programming syntax.

The pre element preserves whitespace, including spaces and line breaks. The code element identifies the content as computer code. Using pre together with code makes the examples appear as preserved preformatted code blocks rather than ordinary paragraphs.
